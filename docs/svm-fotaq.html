Flight of the Amazon Queen

A cosa serve

Avventura comica: il pilota Joe King precipita nella giungla amazzonica e deve fermare uno scienziato pazzo. Versione CD parlata. (Interactive Binary Illusions, 1995.)

Come si usa

Nella pagina dello Store scegli la lingua, poi installa. Al primo avvio il gioco scarica i suoi file originali dal sito di ScummVM (35-77 MB, serve il Wi-Fi), li controlla e parte; le volte successive parte subito. Il download si può interrompere con il gesto Indietro: riprende da dove era rimasto. Gira con il motore ScummVM, che lo Store installa insieme al gioco.

Lingue: English, Italiano (sub), Francais, Deutsch, Hebrew (sub).

Licenza: Freeware (John Passfield, Steve Stamatiadis). I file sono quelli originali, non modificati.

Salvataggi

Ogni gioco salva nella sua cartella: dal menu di ScummVM (gesto Indietro) scegli Save o Load. Disinstallando il gioco i salvataggi si perdono.

Problemi comuni

  • Il download si ferma: controlla il Wi-Fi e riapri il gioco, riprende da dove era rimasto.
  • Nessun suono: un'altra app (per esempio Musica) sta usando l'altoparlante. Chiudila, l'audio torna da solo in pochi secondi.
  • Voglio cambiare lingua: nella pagina del gioco nello Store scegli un'altra lingua. Al prossimo avvio il gioco scarica i file di quella lingua.

Flight of the Amazon Queen

What it is for

Comedy adventure: pilot Joe King crash-lands in the Amazon jungle and must stop a mad scientist. Talkie CD version. (Interactive Binary Illusions, 1995.)

How to use it

Pick the language on the Store page, then install. On first start the game downloads its original files from the ScummVM website (35-77 MB, Wi-Fi needed), checks them and starts; after that it starts straight away. The Back gesture stops the download: it resumes where it stopped. It runs on the ScummVM engine, which the Store installs together with the game.

Languages: English, Italiano (sub), Francais, Deutsch, Hebrew (sub).

Licence: Freeware (John Passfield, Steve Stamatiadis). The files are the original ones, unmodified.

Controls

Action Touch Mouse Keyboard Gamepad
Walk / use tap the spot left button – A
Examine (right button) press and hold, or two-finger tap right button – B
Move the pointer drag your finger move – D-pad or left stick
Skip scene / dialogue three-finger tap – Esc X
Skip one line – – . (period) Y
Game menu (save, load) – – F5 Back / Select
ScummVM menu Back gesture – Ctrl+F5 Start

USB or Bluetooth keyboards and mice work together with touch as soon as you plug them in. With a keyboard you can type save names.

Saves

Each game saves in its own folder: from the ScummVM menu (Back gesture) choose Save or Load. Uninstalling the game deletes its saves.

Common problems

  • The download stops: check Wi-Fi and open the game again, it resumes where it stopped.
  • No sound: another app (Music, for example) is using the speaker. Close it, sound comes back on its own within a few seconds.
  • I want another language: pick it on the game's Store page. On the next start the game downloads the files of that language.
