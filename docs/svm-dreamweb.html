DreamWeb

What it is for

Dark top-down cyberpunk thriller for adults: Ryan must kill seven people to save the DreamWeb. Contains violence and nudity. (Creative Reality, 1994.)

How to use it

Pick the language on the Store page, then install. On first start the game downloads its original files from the ScummVM website (10-244 MB, Wi-Fi needed), checks them and starts; after that it starts straight away. The Back gesture stops the download: it resumes where it stopped. It runs on the ScummVM engine, which the Store installs together with the game.

Languages: English, Italiano (CD), Francais (CD), Deutsch (CD), Espanol (CD), English (CD).

Licence: Freeware (Creative Reality, unmodified). The files are the original ones, unmodified.

USB or Bluetooth keyboards and mice work together with touch as soon as you plug them in. With a keyboard you can type save names.

Saves

Each game saves in its own folder: from the ScummVM menu (Back gesture) choose Save or Load. Uninstalling the game deletes its saves.

Common problems

  • The download stops: check Wi-Fi and open the game again, it resumes where it stopped.
  • No sound: another app (Music, for example) is using the speaker. Close it, sound comes back on its own within a few seconds.
  • I want another language: pick it on the game's Store page. On the next start the game downloads the files of that language.
