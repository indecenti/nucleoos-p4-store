sc-im, foglio di calcolo

A cosa serve

sc-im è un foglio di calcolo vero, a schermo intero: celle con numeri, testi e formule che si ricalcolano da sole, funzioni (@sum, @avg, @max, @if, date e ore), formati dei numeri, larghezza delle colonne, ordinamento, filtri, annulla e ripeti. Apre file Excel .xlsx e .xls, LibreOffice .ods, .csv e .tsv, e salva in .xlsx, .csv e .tsv: un elenco di spese, un inventario, un piano rate, un foglio ricevuto per mail.

Come si apre

  • Tocca l'icona in Home: si apre il foglio vuoto.
  • Da File, tocca un .xlsx, .xls, .ods o .csv e scegli Apri con › sc-im.
  • Dal Terminale: sc-im spese.xlsx.

Tocco e tastiera

  • Tocca una cella per selezionarla. Trascina su e giù per scorrere il foglio.
  • La riga di tasti sopra la tastiera ha Esc, Tab, Ctrl e le frecce.
  • Con una tastiera USB o KeyDeck funzionano anche Ctrl, Shift e i tasti funzione.

I comandi principali

sc-im si usa come l'editor vim: una lettera è un comando, i comandi lunghi cominciano con i due punti.

Tasti Cosa fanno
frecce spostano la selezione
= scrivi un numero o una formula, es. =@sum(B0:B9) poi Invio
< > \ scrivi un testo allineato a sinistra, a destra, centrato
e / E modifica il numero / il testo della cella
x cancella la cella
u / Ctrl+R annulla / ripeti
yy poi p copia la cella e incollala
ir ic inserisci una riga / una colonna
dr dc elimina la riga / la colonna
f> f< colonna più larga / più stretta
f+ f- più / meno decimali
goB12 vai alla cella B12
:w salva; :w conti.xlsx salva come Excel
:e csv conti.csv esporta in CSV (anche tab, txt, mkd)
:load file.ods apre un altro file
:q esce (:q! senza salvare)
:h il manuale completo (q per chiuderlo)

Le celle si chiamano con la colonna e la riga, contando le righe da 0: A0 è la prima cella in alto a sinistra. Nelle formule gli intervalli si scrivono A0:A9.

Con Anima

sc-im è un programma di sistema: Anima lo usa per leggere i tuoi fogli. Chiedi per esempio "quanto fa il totale nel file spese.xlsx?" o "riassumi la tabella ordini.ods".

Limiti

  • Grafici, macro, immagini e commenti dei file Excel non vengono letti; di un .xlsx si leggono valori, testi e (con l'opzione --xlsx_readformulas) le formule.
  • I file .ods si aprono ma si salvano in .xlsx, .csv o nel formato di sc-im (.sc).
  • Di un vecchio .xls si legge il primo foglio; si salva in .xlsx.
  • Gli appunti di sistema e i comandi ! (programmi esterni) non sono disponibili.
  • Fogli molto grandi (decine di migliaia di righe) possono non entrare nella memoria del dispositivo: sc-im lo dice e il file originale resta intatto, perché salva prima in un file temporaneo.

Nel Terminale

  • Tocca l'icona per aprire il Terminale con il programma già avviato, oppure apri Terminale e scrivi il comando.
  • I tuoi file stanno nella cartella home della scheda SD (/sdcard/home): per il programma quella cartella è /. Puoi copiarci file dal PC mettendo la SD nel lettore.
  • Leggere un foglio senza aprirlo: sc-im --nocurses --quit_afterload --export_csv spese.xlsx (con --export_mkd esce una tabella).
  • Con apps il Terminale elenca i programmi installati, con help sc-im la sintassi.

sc-im, spreadsheet

What it is for

sc-im is a real full-screen spreadsheet: cells with numbers, text and formulas that recalculate by themselves, functions (@sum, @avg, @max, @if, dates and times), number formats, column widths, sorting, filters, undo and redo. It opens Excel .xlsx and .xls, LibreOffice .ods, .csv and .tsv files, and saves .xlsx, .csv and .tsv: a list of expenses, an inventory, a loan plan, a sheet someone emailed you.

How to open it

  • Tap the icon on Home: an empty sheet opens.
  • In Files, tap an .xlsx, .xls, .ods or .csv file and choose Open with › sc-im.
  • In the Terminal: sc-im expenses.xlsx.

Touch and keyboard

  • Tap a cell to select it. Drag up and down to scroll the sheet.
  • The key row above the keyboard has Esc, Tab, Ctrl and the arrows.
  • A USB or KeyDeck keyboard also gives you Ctrl, Shift and the function keys.

The main commands

sc-im works like the vim editor: a letter is a command, long commands start with a colon.

Keys What they do
arrows move the selection
= type a number or a formula, e.g. =@sum(B0:B9) then Enter
< > \ type text aligned left, right, centred
e / E edit the cell's number / text
x delete the cell
u / Ctrl+R undo / redo
yy then p copy the cell and paste it
ir ic insert a row / a column
dr dc delete the row / the column
f> f< wider / narrower column
f+ f- more / fewer decimals
goB12 go to cell B12
:w save; :w accounts.xlsx saves as Excel
:e csv accounts.csv export to CSV (also tab, txt, mkd)
:load file.ods open another file
:q quit (:q! without saving)
:h the full manual (q closes it)

Cells are named by column and row, counting rows from 0: A0 is the top-left cell. Ranges in formulas are written A0:A9.

With Anima

sc-im is a system program: Anima uses it to read your sheets. Ask for example "what is the total in expenses.xlsx?" or "summarise the orders.ods table".

Limits

  • Charts, macros, pictures and comments in Excel files are not read; from an .xlsx you get values, text and (with the --xlsx_readformulas option) formulas.
  • .ods files open but save as .xlsx, .csv or sc-im's own format (.sc).
  • From an old .xls file the first sheet is read; it saves as .xlsx.
  • The system clipboard and ! commands (external programs) are not available.
  • Very large sheets (tens of thousands of rows) may not fit in the device's memory: sc-im says so and the original file is left untouched, because it saves to a temporary file first.

In the Terminal

  • Tap the icon to open the Terminal with the program already running, or open Terminal and type the command.
  • Your files live in the home folder of the SD card (/sdcard/home): the program sees that folder as /. Copy files from a PC by putting the SD in a card reader.
  • Read a sheet without opening it: sc-im --nocurses --quit_afterload --export_csv expenses.xlsx (--export_mkd gives a table).
  • apps lists the installed terminal programs, help sc-im its syntax.

sc-im ist eine echte Tabellenkalkulation im Vollbild: Zellen mit Zahlen, Texten und Formeln, die sich selbst neu berechnen, Funktionen (@sum, @avg, @max, @if, Datum und Uhrzeit), Zahlenformate, Spaltenbreiten, Sortieren, Filter, Rückgängig und Wiederholen.
