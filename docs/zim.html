zim

A cosa serve

zim legge i file ZIM della libreria Kiwix: Wikipedia, Wikizionario, Wikivoyage, l'enciclopedia medica, le guide di riparazione di iFixit, la documentazione dei linguaggi di programmazione (DevDocs), i libri di Gutenberg e molto altro, senza Internet. Il catalogo ne conta migliaia, in tutte le lingue, aggiornati ogni mese.

Una voce esce come testo pulito: titolo, paragrafi, elenchi, tabelle in righe. Note, link di modifica e menu di navigazione restano fuori. ANIMA usa lo stesso programma quando una risposta è nella biblioteca.

Come si usa

Comando Cosa fa
zim ls elenca le raccolte in ~/zim
zim search diabete i titoli che iniziano così, in tutte le raccolte (maiuscole indifferenti)
zim get Insulina la voce intera come testo
zim get 'Giuseppe Garibaldi' --intro solo l'introduzione
zim get 'Diabete mellito' --sections l'elenco delle sezioni
zim get 'Diabete mellito' --section Terapia una sezione sola
zim get -z medicina Insulina cerca solo nella raccolta indicata (basta una parte del nome)
zim get Insulina --max 2000 al massimo 2000 caratteri
zim get Insulina --all tiene anche note, bibliografia e collegamenti
zim random l'inizio di una voce a caso
zim info medicina titolo, lingua, data, numero di voci di una raccolta
zim check medicina controlla che il file non sia danneggiato

Si combina con la shell: zim get Insulina > insulina.txt salva la voce in un file, zim get -z wikipedia img/foto.webp --out foto.webp estrae un'immagine o un altro file.

Dove prendere i file

Dal sito della libreria Kiwix (library.kiwix.org) si scaricano sul PC i file .zim che interessano, poi si copiano nella cartella zim della home della scheda SD (/sdcard/home/zim) con il lettore di schede. Per le schede FAT32 e per i file oltre 2 GB servono i file divisi in parti (nome.zimaa, nome.zimab…): zim li legge come un file solo.

Per cominciare vanno bene le versioni nopic (solo testo) o mini (solo le introduzioni): Wikipedia in italiano top_nopic pesa circa 900 MB, il Wikizionario circa 360 MB, l'enciclopedia medica circa 90 MB.

Limiti

La ricerca trova i titoli che iniziano con le parole scritte; il testo completo delle voci non è ancora indicizzato. Se una voce non ha un titolo scritto come lo digiti e non ha un rinvio, prova con le maiuscole giuste o con zim search. Le immagini e le formule non si vedono nel Terminale: delle formule appare il codice TeX. Le raccolte fatte con zimit (copie di siti interi) danno risultati più grezzi.

Nel Terminale

  • Tocca l'icona per aprire il Terminale con il programma già avviato, oppure apri Terminale e scrivi il comando.
  • Scrivi nella riga in basso e premi Invio: la riga va al programma.

  • I tuoi file stanno nella cartella home della scheda SD (/sdcard/home): per il programma quella cartella è /. Puoi copiarci file dal PC mettendo la SD nel lettore.

>_ Terminal program

It has no window of its own: it runs inside the Terminal app. Tapping its icon opens the Terminal with the program already started; or open Terminal and type zim.

zim

What it is for

zim reads the ZIM files of the Kiwix library: Wikipedia, Wiktionary, Wikivoyage, the medical encyclopedia, iFixit's repair guides, programming language documentation (DevDocs), Gutenberg's books and much more, with no Internet. The catalog has thousands of them, in every language, updated every month.

An article comes out as clean text: title, paragraphs, lists, tables as rows. Footnotes, edit links and navigation menus are left out. ANIMA uses the same program when an answer is in the library.

How to use it

Command What it does
zim ls lists the collections in ~/zim
zim search diabetes titles starting like that, in every collection (any case)
zim get Insulin the whole article as text
zim get 'Albert Einstein' --intro the introduction only
zim get 'Diabetes' --sections the list of sections
zim get 'Diabetes' --section Treatment one section
zim get -z medicine Insulin only in that collection (part of its name is enough)
zim get Insulin --max 2000 at most 2000 characters
zim get Insulin --all keeps notes, references and links too
zim random the beginning of a random article
zim info medicine title, language, date, number of articles of a collection
zim check medicine checks the file is not damaged

It works with the shell: zim get Insulin > insulin.txt saves the article to a file, zim get -z wikipedia img/photo.webp --out photo.webp extracts an image or another file.

Where to get the files

From the Kiwix library site (library.kiwix.org) download the .zim files you want on a PC, then copy them into the zim folder of the SD card's home (/sdcard/home/zim) with a card reader. FAT32 cards and files over 2 GB need the files split in parts (name.zimaa, name.zimab…): zim reads them as one file.

To start, the nopic (text only) or mini (introductions only) versions are fine: English Wikipedia top_mini is about 280 MB, the medical encyclopedia about 90 MB.

Limits

Search finds titles that start with the words you type; the full text of the articles is not indexed yet. If an article has no title written the way you type it and no redirect, try the right capitals or zim search. Images and formulas cannot be shown in the Terminal: formulas appear as their TeX code. Collections made with zimit (copies of whole websites) give rougher results.

In the Terminal

  • Tap the icon to open the Terminal with the program already running, or open Terminal and type the command.
  • Type in the bottom line and press Enter: the line goes to the program.
  • EOF ends the input (like Ctrl-D): many programs then finish. STOP kills it right away.
  • Your files live in the home folder of the SD card (/sdcard/home): the program sees that folder as /. Copy files from a PC by putting the SD in a card reader.
  • apps lists the installed terminal programs, help the Terminal's own commands.
