Come si usa

Nella pagina dello Store scegli la lingua, poi installa. Il download si può interrompere con il gesto Indietro: riprende da dove era rimasto. Gira con il motore ScummVM, che lo Store installa insieme al gioco.

Lingue: English, Italiano, Espanol, Francais, Deutsch.

Licenza: Freeware (Alcachofa Soft). I file sono quelli originali, non modificati.

Drascula: The Vampire Strikes Back

What it is for

Spanish comedy adventure: John Hacker travels to Transylvania to rescue his girlfriend from the vampire Drascula. With the CD soundtrack. (Alcachofa Soft, 1996.)

How to use it

Pick the language on the Store page, then install. On first start the game downloads its original files from the ScummVM website (70-104 MB, Wi-Fi needed), checks them and starts; after that it starts straight away. The Back gesture stops the download: it resumes where it stopped. It runs on the ScummVM engine, which the Store installs together with the game.

Languages: English, Italiano, Espanol, Francais, Deutsch.

Licence: Freeware (Alcachofa Soft). The files are the original ones, unmodified.

Controls

Action Touch Mouse Keyboard Gamepad
Walk / use tap the spot left button – A
Examine (right button) press and hold, or two-finger tap right button – B
Move the pointer drag your finger move – D-pad or left stick
Skip scene / dialogue three-finger tap – Esc X
Skip one line – – . (period) Y
Game menu (save, load) – – F5 Back / Select
ScummVM menu Back gesture – Ctrl+F5 Start

USB or Bluetooth keyboards and mice work together with touch as soon as you plug them in. With a keyboard you can type save names.

Saves

Each game saves in its own folder: from the ScummVM menu (Back gesture) choose Save or Load. Uninstalling the game deletes its saves.

Common problems

  • The download stops: check Wi-Fi and open the game again, it resumes where it stopped.
  • No sound: another app (Music, for example) is using the speaker. Close it, sound comes back on its own within a few seconds.
  • I want another language: pick it on the game's Store page. On the next start the game downloads the files of that language.
